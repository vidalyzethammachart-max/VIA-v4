## ควรแก้ก่อนเปิดใช้จริง (ถามผมก่อนลงมือ)
- workflow ล้มแล้วไม่ส่งสถานะ failed กลับมา ผู้ใช้เห็นค้าง processing
- n8n webhook ไม่มีการยืนยันตัวตน

## ข้อห้ามและวิธีทำงาน
- ห้ามเรียก n8n REST (/rest/) ด้วย JavaScript fetch จากหน้าเว็บ เคยทำแล้วได้ 401 และ session หลุด ต้องล็อกอินใหม่
  ให้อ่านข้อมูล execution ผ่าน UI แทน (รายละเอียด request อยู่ใต้ "From HTTP Request" ในโหนด Analyze Video)
- ห้ามอ่าน แสดง หรือ commit ค่า secret และห้ามส่ง key ในแชต ให้ผมกรอก credential เอง
- การแก้ production (n8n, Render, billing) ต้องยืนยันกับผมก่อน
- อย่า retry งานเก่าหรือรีเซ็ต guard เองโดยอัตโนมัติ
- รายงานตามจริง สิ่งที่ยังไม่ได้ทดสอบให้บอกว่ายังไม่ได้ทดสอบ
- execution ใน n8n สำเร็จ กับ PDF/DOCX เปิดได้จริง เป็นคนละเรื่อง ต้องตรวจทั้งคู่
